# Image Checklist

Use this checklist before adding website images.

- Use WEBP for website images when possible.
- Keep normal images under 300 KB if possible.
- Avoid large PNG files unless transparency or exact quality is required.
- Do not upload videos directly into the website repo.
- Put large assets in external storage later.
- Keep image names lowercase and descriptive.
- Store chapter images inside that chapter folder's `images/` folder.
