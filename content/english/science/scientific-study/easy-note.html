Quick Revision Summary

  • A unit makes measurement clear.
  • A fair experiment changes one main thing at a time.
  • Independent variable is changed; dependent variable is measured.
  • Controlled variables are kept the same.
  • Dimensional validity checks whether units match on both sides.

Quick Key Terms

Unit

A fixed standard used to measure something.

Example: metre is a unit of length.

Fundamental unit

A basic unit that is not made from other units.

Example: kilogram, metre, second.

Derived unit

A unit made by joining fundamental units.

Example: newton = kg m s-2.

Independent variable

The thing we change in an experiment.

Example: amount of water given to a plant.

Dependent variable

The result we measure in an experiment.

Example: height or growth of the plant.

Controlled variable

The things we keep the same so the experiment is fair.

Example: same seed, soil, sunlight, and pot size.

Memory trick: Change one thing, measure one result, and keep other things the same.

Very Short Answer

Q. What is a unit?

Answer: A unit is a fixed standard used to measure a physical quantity. Without a unit, a number is not clear.

Example: If a table is 1 metre long, metre (m) is the unit of length.

Important point: Always write number and unit together, such as 5 m, 2 kg, or 10 s.
Memory trick: A unit is the measuring name. 5 alone is confusing, but 5 m is clear.

Short Answer

Q. Write the SI units of mass, temperature, energy, and density.

Answer: The SI unit of mass is kilogram (kg). The SI unit of temperature is kelvin (K). The SI unit of energy is joule (J). The SI unit of density is kilogram per cubic metre (kg/m3).

Example: Mass is measured in kg, while energy used by a machine is measured in J.

Important point: Write symbols correctly: kg, K, J, and kg/m3.
Memory trick: Mass, Temperature, Energy, Density = kg, K, J, kg/m3.

Q. How is the validity of an equation checked?

Answer: The validity of an equation is checked by comparing the unit or dimension on the left side and right side. If both sides have the same unit, the equation is dimensionally valid.

Working steps:

  • Write the unit of the left-hand side.
  • Write the unit of the right-hand side.
  • If both units are the same, the equation is dimensionally valid.
  • Example: s = vt. Unit of s = m. Unit of vt = (m/s) × s = m. So, s = vt is dimensionally valid.
Important point: Dimensional validity only checks units. It does not always prove the formula is fully correct.
Memory trick: Both sides of an equation must wear the same unit dress.

Q. Mention the fundamental units involved in pressure.

Answer: Pressure = Force / Area. So, Pa = N/m2 = kg m-1 s-2. The fundamental units involved are kilogram (kg), metre (m), and second (s).

Working steps:

  • Pressure = Force / Area
  • Force = N = kg m s-2
  • Area = m2
  • Pressure = kg m s-2 / m2 = kg m-1 s-2
Important point: Pressure uses kg, m, and s only.
Memory trick: Pressure pushes on area, so remember P = F/A.

Q. Find the fundamental units in N, W, J, and Pa.

Answer: A derived unit can be written using fundamental units such as kg, m, and s.

  • Newton (N) = kg m s-2
  • Watt (W) = kg m2 s-3
  • Joule (J) = kg m2 s-2
  • Pascal (Pa) = kg m-1 s-2
Important point: These four derived units are common in SEE numerical questions.
Memory trick: N is force, J is work, W is power, and Pa is pressure.

Long Answer

Q. Describe independent, dependent, and controlled variables with an example.

Answer: In an experiment, the independent variable is the thing we change. The dependent variable is the result we measure. Controlled variables are the things we keep the same to make the experiment fair.

Example: To test how water affects plant growth, change the amount of water. Measure the height of the plant. Keep the same seed, soil, pot size, sunlight, and place.

Important point: A good experiment usually changes only one main thing at a time.
Memory trick: I-D-C means I change, D shows result, C stays constant.

Give Reason

Q. Joule is the derived unit of work.

Answer: Joule is a derived unit because work is calculated from force × displacement. Force has unit newton and displacement has unit metre. So, J = N m = kg m2 s-2, which is made from fundamental units.

Example: Work done while pushing an object is measured in joule.

Important point: Work = Force × displacement, so joule is not a fundamental unit.
Memory trick: Joule is a joined unit because it joins N and m.

Q. Some variables should be controlled while performing an experiment.

Answer: Some variables should be controlled to make the experiment fair and reliable. If many things change together, we cannot know which thing caused the result.

Example: If we test plant growth by changing fertilizer, then pot size, water, sunlight, and seed type should be the same.

Important point: Controlled variables help us find the real cause.
Memory trick: Fair test = one change, other things same.

Q. v2 = ut is not a valid relation.

Answer: The relation is not valid because the units on both sides are not the same.

Working steps:

  • Unit of v = m/s, so unit of v2 = m2/s2.
  • Unit of u = m/s and unit of t = s.
  • So, unit of ut = (m/s) × s = m.
  • m2/s2 is not equal to m. Therefore, v2 = ut is not valid.
Important point: For a valid relation, LHS unit and RHS unit must match.
Memory trick: Same equation needs same unit on both sides.

Q. Why did Chandani use three pots for each experiment?

Answer: Chandani used three pots for each experiment to get a more reliable result. If one pot grows badly by chance, the other pots help her compare better and take an average idea.

Example: Repeating a plant growth test with more than one pot reduces the chance of a wrong conclusion.

Important point: Repeating the same test reduces error.
Memory trick: More trials = more trust.

Differentiate Between

Q. Independent variable and dependent variable

Basis Independent variable Dependent variable
Meaning The thing we change. The result we measure.
Role It affects the experiment. It is affected by the independent variable.
Example Amount of water given to a plant. Height or growth of the plant.
Important point: The dependent variable depends on what was changed.
Memory trick: Independent = I change. Dependent = depends on what I changed.

Q. Fundamental unit and derived unit

Basis Fundamental unit Derived unit
Meaning A basic unit that is not made from other units. A unit made from two or more basic units.
Example metre, kilogram, second, kelvin newton, joule, pascal, watt

Important point: Derived units are made by combining fundamental units.
Memory trick: Fundamental = foundation. Derived = made from foundation units.

Numerical Questions

Q. Check the validity of P = mv2/t for power and P = mv/A for pressure.

Answer: P = mv2/t has the same dimension as power, so it is dimensionally valid. P = mv/A is not valid for pressure because its unit is not the same as pressure.

Working steps:

  • For power: mv2/t = kg × (m/s)2 / s = kg m2 s-3.
  • Power has unit watt = kg m2 s-3. So, mv2/t is dimensionally valid for power.
  • For pressure: mv/A = kg × (m/s) / m2 = kg m-1 s-1.
  • Pressure should be kg m-1 s-2. So, mv/A is not valid for pressure.
Important point: Same unit means dimensionally valid, but a formula may still need correct physical meaning.
Memory trick: Power is energy per second. Pressure is force per area.

Q. Prove that the unit of resistance ohm (Ω) = kg m2 s-3 A-2.

Answer: Electric resistance is voltage divided by current. So, Ω = V/A. Voltage can be written as kg m2 s-3 A-1. Therefore, Ω = kg m2 s-3 A-2.

Working steps:

  • Resistance, R = V/I.
  • Voltage, V = Work / Charge.
  • Work = J = kg m2 s-2.
  • Charge = current × time = A s.
  • So, V = kg m2 s-2 / A s = kg m2 s-3 A-1.
  • Now, Ω = V/A = kg m2 s-3 A-1 / A = kg m2 s-3 A-2.
Important point: Ohm contains kg, m, s, and A.
Memory trick: R = V/I. Divide voltage by current, so A becomes A-2.

Application / Analytical Questions

Q. How does wire thickness affect the life span of a dry cell?

Answer: The independent variable is the thickness of the wire. The dependent variable is the life span of the dry cell. Controlled variables are the same dry cell type, same bulb, same wire length, same circuit connection, and same testing condition.

Example: Only the wire thickness should change while testing the circuit.

Important point: Other parts of the circuit should stay the same.
Memory trick: Change thickness, measure cell life, keep circuit same.

Q. Identify variables in Chandani's plant growth experiment.

Answer: The independent variable is the substance mixed with soil, such as salt, fertilizer, or compost. The dependent variable is plant growth, mainly plant height. Controlled variables are same pot size, same amount of soil, same seed type, same amount of water, same sunlight, same place, and same amount of substance.

Example: If compost is changed, all other plant conditions should remain the same.

Important point: Plant height is the measured result, so it is the dependent variable.
Memory trick: Soil substance changes; plant height answers.

Q. Does colour affect an object's ability to hold heat?

Answer: The independent variable is the colour of the flask. The dependent variable is the temperature of water in the flask. Controlled variables should be same flask size and material, same amount of water, same starting temperature, same time in sunlight, same place, same cork, and same thermometer method.

Example: Use the same amount of water in different coloured flasks and measure temperature after the same time.

Important point: Colour changes, but temperature is measured.
Memory trick: Change colour, check heat.

Q. What is wrong with Manisha's dog feeding experiment?

Answer: The mistake is that Manisha is changing two things at the same time: amount of food and time of giving food. Then she cannot know which factor changed the eating speed. She should test only one factor at a time.

Working steps:

  • Method 1: Change only the amount of food, but keep feeding time the same.
  • Method 2: Change only the feeding time, but keep food amount the same.
  • Keep the same dog, same food type, same bowl, same place, and similar hunger condition.
Important point: A fair experiment changes one independent variable at a time.
Memory trick: Two changes together = confusing result.

Activity / Practical Questions

Q. Activity: Making a catapult from a rubber band

Answer: A rubber band catapult shows how stored energy changes into motion. When we stretch the rubber band, energy is stored in it. When we release it, the stored energy moves the small object forward.

Working steps:

  • Take a rubber band, ice-cream sticks or pencils, and a small paper ball.
  • Fix the rubber band safely on the support.
  • Pull the rubber band back gently with the paper ball.
  • Release it and observe how far the paper ball goes.
  • Do not aim at any person, animal, or glass object.
Important point: This activity shows elastic potential energy changing into kinetic energy.
Memory trick: Stretch = store energy. Release = motion.

Answer: We use many units in daily life. Fundamental units measure basic quantities. Derived units are made from fundamental units.
